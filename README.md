# Shanta Institute of Technology (SIT), Kalaburagi

Official institutional portal and web platform for **Shanta Institute of Technology** (A Unit of SGI &bull; Established 2011 &bull; KCET Code: E227), affiliated to Visvesvaraya Technological University (VTU) Belagavi and approved by AICTE New Delhi.

---

## 🌟 Highlights & Features

- **Dynamic Homepage**: Highlighting 22-acre eco-friendly campus, academic pillars, admissions guidelines, and faculty directory.
- **Student Self Governance Council**: Showcasing elected student leadership, club executives, and administrative forums.
- **Achievements & Awards Gallery**: Interactive high-resolution lightbox featuring state and national laureates, COMED KARES UI Design championship, VTU Cybersecurity CTF ranks, and INEX International Innovation medals.
- **Experiential Pedagogy & PBL**: Project-Based Learning modules, incubation hub, and research strategy consultations.
- **Student & Faculty CMS Portals**: Direct access to semester notes, exam schedules, lecture presentations, and administrative circulars.

---

## 🚀 Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Motion
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Server/Deploy**: Node.js / Express

---

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/zaheerjklabs/College-Website.git
   cd College-Website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
